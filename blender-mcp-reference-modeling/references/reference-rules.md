# Reference and Dimension Rules

## Priority

Use this default conflict order unless the user freezes another order:

1. dimension table and explicit annotations;
2. orthographic plan/elevation/section views;
3. approved 45-degree perspective view;
4. quality-only or atmosphere-only inspiration images;
5. agent inference.

Never use a quality reference to replace the structure defined by the design sheet.

## Freeze procedure

Before modeling:

1. Record units, axes, origin, site bounds, object dimensions, clearances, counts, and locations.
2. Separate hard constraints from estimated details.
3. Identify inconsistent views and quantify the conflict when possible.
4. Ask the user to resolve any conflict that changes structure, proportion, layout, color, or deliverables.
5. Save the approved result in a project brief and do not reinterpret it during modeling.

## Orthographic calibration

- Calibrate each view with explicit dimensions, not image borders.
- Treat side view as X-Z, top view as X-Y, and front/rear views as Y-Z constraints.
- Keep sensors, antennas, lamps, and accessories separate from primary body height when the dimension table does so.
- For a vehicle, lock overall length/width/height, wheel centers, wheelbase, overhangs, track width, wheel diameter, clearance, and ground line before shaping the shell.
- Use transparent overlays to evaluate silhouette. Do not claim millimeter precision when the source resolution cannot support it.

## Inference boundary

Infer only unannotated, low-impact details whose omission blocks modeling. Label the inference, base it on the nearest orthographic view, and keep it reversible. Ask before any inference that changes a major form, layout, material class, or visible design language.
