# Single Room Hard-Finish Handoff

Use the supplied fire plan for room 218's relation to the corridor. Use the attached BOT paper as the reasoning reference: model the room as a `bot:Space`, model walls/doors/windows/floor/ceiling as `bot:Element` constituents, and model the door and window boundaries as interfaces.

## Required shell

- Complete floor and ceiling.
- Four wall boundaries, split only where the door and window openings occur.
- Front door opening with two jambs, a head, wall above the head, threshold, and door leaf.
- Back exterior window opening with side piers, sill, head, frame, and glazing.
- Corridor threshold context so the room-to-corridor connection is legible.
- Hard finishes only. No bed, desk, wardrobe, chair, plant, or decoration.

## Acceptance

The cutaway must prove the room is a real volume. The interior view must show the door interface and wall above it. The audit must report missing shell elements and must confirm no furniture objects exist.
